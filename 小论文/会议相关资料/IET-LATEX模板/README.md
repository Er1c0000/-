# IET_LaTeX模板使用说明

此压缩文件包含了一份由IET（国际电气与电子工程师学会）官方提供的投稿模板，适用于投稿至IET旗下的期刊。该模板名为“IET_LaTeX模板.zip”，内含完整的LaTeX格式化文件，旨在帮助作者按照IET的格式要求准备文稿。

## 模板内容
- **main.tex**：主文档文件，用于撰写文章。
- **iet.bst**：参考文献格式文件，确保参考文献格式符合IET要求。
- **iet.cls**：文档类文件，定义了IET期刊的格式规范。

## 使用方法
1. 解压“IET_LaTeX模板.zip”到您的电脑上。
2. 使用支持LaTeX的编辑器（如TeXstudio、Overleaf等）打开“main.tex”文件。
3. 根据您的文章内容，编辑“main.tex”文件。
4. 编译LaTeX文件，生成PDF文档以查看文章格式。

## 注意事项
- 使用此模板时，请确保您的文章内容符合IET期刊的投稿要求。
- 请勿修改“iet.cls”和“iet.bst”文件，以免影响文章格式。

使用此模板，您可以更加便捷地准备符合IET格式标准的学术论文，提高投稿效率。祝您投稿顺利！
