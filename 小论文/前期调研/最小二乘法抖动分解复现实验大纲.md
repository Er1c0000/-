# 最小二乘法抖动分解复现实验大纲

## 一、 实验目标

复现论文中提出的基于最小二乘法（Least Squares, LS）的抖动分离算法，从时间间隔误差（TIE）序列中准确提取出以下抖动分量：

1. **周期性抖动 (PJ)**：幅值与频率。
2. **占空比失真 (DCD)**：幅值。
3. **码间干扰 (ISI)**：不同码型组合下的抖动贡献及峰峰值。
4. **随机抖动 (RJ)**：均方根值（RMS）。

------

## 二、 阶段一：数据准备与仿真环境搭建

*目标：生成可控的、包含已知抖动分量的测试数据，作为算法的输入（Ground Truth）。*

### 1. 基础信号生成

- **信号类型**：生成伪随机二进制序列（PRBS，如 PRBS-7 或 PRBS-9）。
- **参数设定**：
  - 数据速率 ($f_s$)：例如 2.5 Gbps 或 10 Gbps。
  - 采样率 ($F_{sample}$)：需满足奈奎斯特采样定理，且为了模拟真实示波器，建议设置过采样（例如每比特 4-8 个采样点）。
  - 数据长度 ($M$)：需包含至少一个完整的 PJ 周期和足够的 PRBS 码型组合（参考论文公式 4-55）。

### 2. 抖动注入模型 (Jitter Injection)

根据公式 4-1，构建带有混合抖动的 TIE 序列：



$$\Delta t_{total}[n] = \Delta t_{DCD}[n] + \Delta t_{ISI}[n] + \Delta t_{PJ}[n] + \Delta t_{RJ}[n]$$

- **DCD 注入**：
  - 模型：$\Delta t_{DCD}[n] = J_{DCD} \cdot (-1)^n$ (假设 $n$ 为边沿索引)。
  - 设定值：例如 $J_{DCD} = 10 \text{ ps}$。
- **ISI 注入**：
  - 模型：基于前 $k$ 位比特（如 $k=5$）的组合生成确定性偏差。
  - 实现：构建一个长度为 $2^k$ 的查找表，随机或按规律赋予抖动值。
- **PJ 注入**：
  - 模型：$\Delta t_{PJ}[n] = A_{PJ} \sin(2\pi f_{PJ} t_n + \phi)$。
  - 设定值：例如 $A_{PJ} = 20 \text{ ps}$, $f_{PJ} = 10 \text{ MHz}$。
- **RJ 注入**：
  - 模型：高斯白噪声 $N(0, \sigma^2)$。
  - 设定值：例如 $\sigma_{RJ} = 2 \text{ ps}$。

### 3. TIE 序列提取 (预处理)

- **过零点检测**：模拟时钟恢复过程，从生成的带抖动波形中提取过零点时间戳。
- **TIE 计算**：$TIE[n] = t_{actual}[n] - t_{ideal}[n]$。
- **输出**：得到观测向量 $Z_M$（即 TIE 序列）和对应的数据位信息 $D$。

## 三、 阶段二：算法核心实现 (Python/Matlab)

*目标：构建系数矩阵并求解线性方程组 $Z = H\theta + V$。*

### 1. 辅助参数提取

- **PJ 频率估计**：对 TIE 序列进行 FFT，提取频谱峰值对应的频率 $f_{PJ}$（作为构建矩阵的已知量）。
- **码型状态识别**：遍历数据序列，确定每个边沿的前 $k$ 位比特状态（例如 $k=5$, 状态空间 $0 \sim 31$）。

### 2. 构建系数矩阵 $H$

根据论文公式 4-54，构建大型稀疏矩阵 $H_M = [A \quad B \quad C]$：

- **子矩阵 A (PJ 部分)**：
  - 列 1: $\sin(2\pi f_{PJ} t_n)$
  - 列 2: $\cos(2\pi f_{PJ} t_n)$
- **子矩阵 B (DCD 部分)**：
  - 列 3: $\cos(n\pi)$ 或序列 $[1, -1, 1, -1, \dots]$
- **子矩阵 C (ISI 部分)**：
  - 列 $4 \sim (4 + 2^{k-1})$: 构建 $M \times 2^{k-1}$ 的矩阵。如果第 $n$ 个边沿对应码型组合 $l$，则该行第 $l$ 列为 1，其余为 0。
  - *注意*：需处理无跳变沿的情况（对应行全为 0 或剔除该行）。

### 3. 最小二乘求解

- **方程**：$Z_M = H_M \cdot \theta$
- **求解**：使用标准 LS 解法 $\hat{\theta} = (H^T H)^{-1} H^T Z$。
  - *工程优化*：建议使用 QR 分解或 SVD 分解求解，避免直接求逆带来的数值不稳定（如 Python 的 `numpy.linalg.lstsq`）。

### 4. 参数分离与计算

从解得的向量 $\hat{\theta}$ 中解析各分量：

- **PJ 幅值**：$A_{PJ} = \sqrt{\hat{\theta}[0]^2 + \hat{\theta}[1]^2}$。
- **DCD 幅值**：$J_{DCD} = \hat{\theta}[2]$。
- **ISI 峰峰值**：$ISI_{pp} = \max(\hat{\theta}_{ISI}) - \min(\hat{\theta}_{ISI})$。
- **RJ (残差)**：计算残差向量 $V = Z - H\hat{\theta}$，求其标准差 $\sigma_{RJ} = \text{std}(V)$。

## 四、 阶段三：验证与对比实验

*目标：验证算法准确性，并评估其在不同条件下的鲁棒性。*

### 1. 基准测试 (Benchmark)

- 使用阶段一生成的标准数据进行测试。
- **指标**：计算提取值与注入值（Ground Truth）的相对误差。
  - Error_PJ = $|A_{calc} - A_{ref}| / A_{ref}$
  - Error_RJ = $|\sigma_{calc} - \sigma_{ref}| / \sigma_{ref}$
  - ...

### 2. 鲁棒性测试

- **噪声压力测试**：逐渐增加 RJ 的强度（降低信噪比），观察 PJ 和 ISI 提取精度的变化。
- **数据量敏感度测试**：改变输入数据长度 $M$（如从 10k 比特减少到 1k），观察算法收敛性和准确度，验证论文中“通过较少数据量准确分离”的结论。
- **ISI 记忆长度测试**：改变构建矩阵时的 $k$ 值（如 $k=3, 5, 7$），观察对 ISI 提取结果的影响。

### 3. 对比实验（可选）

- **对比 FFT 法**：仅用频谱法提取 PJ，对比 LS 法在短数据下的优势。
- **对比平均法**：对比论文 4.3 节提到的“数据模式平均法”提取 DDJ 的效率和精度。
