# Experiment 5 全分量分解结果汇总

本文件汇总两套参数配置下 exp5 实验的全分量分解值与估计误差。
两组配置均采用 **RJ = 5 ps rms**，仅 PJ 幅度不同，便于隔离 PJ/RJ 对估计精度的影响。

- **配置 A**：PJ = 10 ps pk-pk，DCD = 1 ps，ISI = 0.16 ps，RJ = 5 ps rms
- **配置 B**：PJ =  6 ps pk-pk，DCD = 1 ps，ISI = 0.16 ps，RJ = 5 ps rms

每组在 PJ 频率 {0.1, 1.0, 10.0} MHz 下分别跑 LS-FFT 与 SBL（FastRVM + ARD）。

## 小结

**PJ 估计误差对比**（保留本实验核心对比）

| 频率 | 配置 A (PJ=10ps) | 配置 B (PJ=6ps) |
|------|-----------------|-----------------|
|      | LS ∣ SBL        | LS ∣ SBL        |
| 0.1 MHz | 0.250 ∣ **0.015** | 0.439 ∣ **0.011** |
| 1.0 MHz | 1.287 ∣ **0.459** | 0.859 ∣ **0.434** |
| 10.0 MHz | 1.275 ∣ **0.499** | 0.943 ∣ **0.370** |

**关键观察**

1. **SBL 误差水平两组基本一致**（RJ=5ps rms 决定了 SBL 的误差底 ~0.3-0.5 ps）。
2. **LS 误差随 PJ 变化**：A 组 PJ 较大，LS 误差也明显较大（尤其 1/10 MHz 处接近 1.3 ps）；B 组 PJ 变小，LS 误差随之下降。
3. **SBL 对 LS 的优势随 PJ 增大而更明显**：A 组 10 MHz 处 LS=1.28 ps，SBL=0.50 ps（2.6× 更优）。
4. **DCD / ISI / RJ**：两种方法在非 PJ 分量上差距不大；SBL 在 DCD 上略优（0.027 vs 0.042），ISI 有系统性偏差（~0.3 ps，源自历史码型桶的统计噪声）。
