# 大论文第二个点待定方向汇总

## 筛选前提

- 业内已经存在相关成熟方法，研究动机建立在“已有方法仍有明确缺陷、存在可改进空间”之上。
- 方向应尽量与现有小论文形成承接，而不是完全另起炉灶。
- 优先选择可通过仿真闭环验证的方向。
- 非平稳抖动方向暂不考虑。

## 当前待定方向

### 1. 基于成熟 TIE 统一线性分解框架的 DDJ/ISI 物理参数化改进

#### 1.1 方案定位

本方向的核心不是沿着某一篇具体分解论文继续做局部修补，而是回到更通用的工程基础：把 DDJ / ISI 视为由数据模式和信道记忆共同决定的时序偏移，再在这个基础上建立适合后续抖动分解与参数提取的低维表征方法。

更准确地说，这个方向要解决的是：

- 业内早已有较成熟的 DDJ / ISI 工程建模思想；
- 这些思想主要来自高速链路、信号完整性和示波器分析流程，而不依赖某一篇单独论文；
- 但目前仍缺少一种既保留物理可解释性、又适合后续参数化分解与稳健估计的低维建模表达。

#### 1.2 成熟基线与通用工程基础

- 统一分解基线：现有 TIE 统一线性分解模型，通常将 PJ、ISI、DCD、RJ 纳入同一框架联合估计。
- RJ / DJ 统计分解基线：Tail-Fit、Dual-Dirac 等方法在 RJ 与 DJ 总体分离上较成熟，但并不直接提供细粒度的 ISI 建模方式。
- PJ 识别基线：FFT 寻峰、频域谱分析在 PJ 频率识别上是经典基线，但不能单独解决 DDJ / ISI 的物理建模问题。
- DDJ / ISI 的通用工程基础：该领域没有一个像 Tail-Fit 或 FFT 那样名字高度统一的单一算法基线，但存在一条更通用的工程路线：
  - 基于数据模式相关性的 DDJ 表征；
  - 基于 step / pulse response 的 DDJ 预测；
  - 基于 tap / cursor 的有限记忆信道建模；
  - 基于 pattern averaging 或条件均值的 DDJ 提取思路。

也就是说，DDJ / ISI 的成熟性更多体现在“数据模式 + 信道响应 + 有限记忆”这条大路线，而不是某一个单独的标准算法名称。

#### 1.3 核心动机与问题意识

- 现有方法中 ISI 建模往往较粗，在低频 PJ 与 ISI 共存时容易出现共线性，导致 ISI 估计失真。
- 传统 DDJ / ISI 表征往往依赖经验规则、模式枚举或响应展开；
- 这些表达虽然有物理意义，但在参数数量、可移植性和后续联合估计上并不总是理想；
- 如果想把 DDJ / ISI 和其他抖动成分放在一个更完整的分析流程里，就需要更低维、更规整的参数化表达。

因此，这个方向的自然研究动机可以概括为：

> 对于 DDJ / ISI，业界已形成基于数据模式相关性、信道响应和有限记忆模型的成熟建模思路，但现有表达往往较分散，既不够低维，也不够适合后续统一参数提取与稳健估计，因此有必要在保留物理可解释性的前提下，对 DDJ / ISI 建模进行进一步参数化整理。

#### 1.4 文献支撑主线

这条方向的文献线可以分三层理解。

第一层：DDJ 是什么，为什么能被单独刻画

- Kyung Ki Kim, Yong-Bin Kim, Fabrizio Lombardi, *Data dependent jitter (DDJ) characterization methodology*, IEEE DFT, 2005。
- J. Buckwalter, B. Analui, A. Hajimiri, *Predicting Data-Dependent Jitter*, IEEE Transactions on Circuits and Systems II, 2004。

这层文献的作用是建立最基础的工程共识：DDJ 与前序 bit 模式、数据速率、带宽限制、阻抗失配等因素有关，不是纯随机量，而是可分析、可预测、可表征的。

第二层：DDJ / ISI 如何和系统响应联系起来

- B. Analui, J. F. Buckwalter, A. Hajimiri, *Data-dependent jitter in serial communications*, IEEE Transactions on Microwave Theory and Techniques, 2005。
- Aritra Dey, Hong Jiang Song, *Modeling of ISI in high speed serial I/Os terminated with discontinuities*, IEEE EPEPS, 2011。

这层文献的作用是建立本方向最核心的物理基础：DDJ / ISI 可以由单位阶跃响应、脉冲响应、信道记忆来描述，有限记忆滤波器、tap、cursor、响应展开等表达方式都属于同一类思路。

第三层：后续研究如何在这个基础上继续推进

- *Polynomial Chaos modeling for jitter estimation in high-speed links*, IEEE ITC, 2018。
- *Jitter Decomposition of High-Speed Data Signals From Jitter Histograms With a Pole-Residue Representation Using Multilayer Perceptron Neural Networks*, IEEE TEMC, 2019。
- *Variational Inference approach to Jitter decomposition in High-speed Link*, IEEE EPEPS, 2020。

这层文献的作用不是做理论起点，而是说明这个方向后面仍有延续；但近年的工作更多在统计推断、代理建模、学习方法和加速估计上，真正把 DDJ / ISI 物理模型重新组织成更规整参数化表达的工作仍然不多。

#### 1.5 当前可考虑的具体技术路线

为避免和本文件中的“方向 1 / 2 / 3”混淆，这里把本方向内部的实现路线单独记为“路线 A / B / C”：

路线 A：基于 step response 的 DDJ 贡献分解

- 直接从前序 bit 对当前 crossing time 的影响出发建模；
- 强调 DDJ 的物理来源，而非单纯模式标签；
- 更接近早期 DDJ 理论文献，物理解释最强。

路线 B：基于 pulse response / tap 的低维参数化

- 用少量主导抽头代替高维码型枚举；
- 将 ISI 从“2^L 类模式查表”改写为“有限抽头响应叠加”；
- 形式清晰，最容易与现有线性框架拼接。

路线 C：对传统 cursor-convolution 模型做降维化改造

- 保留工程上熟悉的传统 ISI 建模思想；
- 通过参数压缩、主导 cursor 选择或子空间投影降低模型维度；
- 更容易把“成熟做法 + 改进空间”讲清楚。

这三条路线的直观区别是：

- 路线 A：从过零点时间偏移的形成机理角度建模，物理解释最强。
- 路线 B：从有限记忆滤波器角度建模，最容易形成低维参数化表达。
- 路线 C：从传统工程 ISI 模型压缩角度建模，最保守稳妥。

#### 1.6 当前判断

- 这一路线和第一篇小论文承接最自然，目前仍是优先考虑的方向。
- 如果以“最容易和现有小论文衔接、最容易写成新论文”为标准，当前更推荐路线 B，即基于 pulse response / tap 的低维参数化。
- 其优势在于：
  - 比沿着某一篇统一分解论文继续局部修改更通用；
  - 比单纯讲 step response 更容易落成可实现模型；
  - 比全盘继承 cursor-convolution 更有提炼和重构空间；
  - 最容易把研究动机写成“降维、减共线、增强可解释性”。

当前也需要保持一个谨慎判断：

- DDJ / ISI 的很多基础理论问题，主要建立在 2004-2011 这一阶段，因此核心理论文献天然偏老；
- 2017-2020 仍有一些工作在推进高速度、低样本、低成本测试和统计推断，但它们未必都聚焦在“DDJ / ISI 物理子模型重构”这个点上；
- 因此，这个方向更适合被表述为：在一个“已有成熟理论基础、但近年缺少系统性重构”的方向上做深化，而不是追逐一个非常新的热点。

### 2. Tail-Fit / Dual-Dirac 方法在有限样本与复杂 DJ 污染下的稳健改进

- 成熟基线：Tail-Fit、Dual-Dirac 等统计域经典抖动分解方法。
- 核心动机：传统 Tail-Fit 对尾部区间选择敏感，对样本量要求较高，在强 PJ 或复杂 DJ 污染下精度下降明显。
- 改进思路：围绕稳健尾部拟合、GMM 辅助分离、PJ 预抑制、自适应尾部选择等方向进行增强。
- 特点：路径清晰、容易落地，但创新上限相对低于方向 1。

### 3. 成熟统一分解模型下的有限样本误差修正与置信度评估

- 成熟基线：已有联合分解模型和最小二乘/稀疏恢复类方法。
- 核心动机：在短观测窗、低信噪比、有限边沿样本条件下，参数估计容易出现偏差和不稳定。
- 改进思路：研究偏差修正、窗口长度自适应、参数置信区间估计、不确定性评估等机制。
- 特点：更偏稳健性和工程化，适合作为“有限采样条件下鲁棒估计”这一问题的展开方向。

## 当前判断

- 主推方向：方向 1，DDJ / ISI 物理参数化改进。
- 备选方向：方向 2，Tail-Fit / Dual-Dirac 稳健改进。
- 可保留观察：方向 3，有限样本误差修正与置信度评估。
