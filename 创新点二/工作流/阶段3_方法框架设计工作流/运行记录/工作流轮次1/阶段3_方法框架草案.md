## 方法总览

- 整体目标：
  - 在保持现有活跃频率识别优势的前提下，提升低频 `PJ-ISI` 高相关场景中的弱分量恢复稳定性与分量解释一致性。
- 总体思路：
  - 保留第一创新点已经成熟的前端支持识别与初始联合分解；
  - 在其后端增加一个 `条件触发` 的局部增强层；
  - 该增强层只在 `PJ-ISI` 高相关风险子空间内工作，执行 `相关性诊断 -> 结构化解耦 -> 局部再估计 -> 一致性检查`；
  - 再将稳定化后的局部结果回写到全局四分量估计中。

## 模块划分

- 承接模块：
  - `TIE 序列建模与字典构造模块`
  - `FastRVM 粗定位模块`
  - `ARD 精细推断与原始四分量联合估计模块`
- 新增模块：
  - `低频 PJ-ISI 高相关风险诊断模块`
  - `PJ/ISI 结构化解耦模块`
  - `局部再估计与一致性检查模块`
- 支撑模块：
  - `触发条件与阈值管理接口`
  - `评价指标输出接口`

## 模块输入输出

- 模块1：前端支持识别与原始联合分解
  - 输入：
    - TIE 序列；
    - 码型相关先验；
    - RJ / PJ / ISI / DCD 分解字典。
  - 输出：
    - 活跃 PJ 支持集；
    - 原始四分量估计；
    - 残差与相关字典子块。
- 模块2：高相关风险诊断
  - 输入：
    - 活跃低频 PJ 列；
    - ISI 子字典；
    - 原始估计残差；
    - 基础相关性统计量。
  - 输出：
    - 高风险 `PJ-ISI` 子空间标记；
    - 是否触发局部解耦的判定结果；
    - 诊断指标集合。
- 模块3：结构化解耦与局部再估计
  - 输入：
    - 高风险 `PJ` 子块；
    - 对应 `ISI` 子块；
    - 原始局部估计值；
    - 触发判定结果。
  - 输出：
    - 解耦后的局部参数估计；
    - 更新后的 `PJ / ISI` 分量；
    - 局部稳定性统计量。
- 模块4：一致性检查与结果回写
  - 输入：
    - 解耦后局部估计；
    - 未改动的 `RJ / DCD` 与其余稳定子块估计；
    - 原始全局估计结果。
  - 输出：
    - 最终稳定化四分量估计；
    - 是否接受本次局部修正的判定；
    - 供阶段4调用的评价接口。

## 与第一创新点接口

- 上游输入接口：
  - 第一创新点输出的活跃 `PJ` 支持集与原始多分量估计，是第二创新点默认上游入口。
- 接口依赖关系：
  - 阶段3不重新执行全局频率发现，而是在 `支持集已锁定` 条件下处理局部相关性失稳。
- 当前不改动的已有部分：
  - 前端字典构造逻辑；
  - `FastRVM 粗定位`；
  - `ARD` 主体支持识别与原始全局联合分解主线。

## 关键流程

- 步骤1：
  - 基于第一创新点前端结果锁定活跃支持集与原始四分量估计。
- 步骤2：
  - 对活跃低频 `PJ` 列与 `ISI` 子字典做相关性诊断，判断是否存在高风险子空间。
- 步骤3：
  - 仅对高风险 `PJ/ISI` 子块执行结构化解耦与局部再估计。
- 步骤4：
  - 做一致性检查与结果回写，得到最终稳定化分解输出。

## 关键假设

- 假设1：
  - 第一创新点已经能够提供基本可靠的活跃支持集与原始四分量初值。
- 假设2：
  - 当前失稳主要集中在有限的 `低频 PJ-ISI` 高相关子空间，而不是全局所有分量同时失效。
- 假设3：
  - 条件触发的局部解耦，不必重写全局分解器，也有机会改善弱分量恢复稳定性。

## 主要技术难点

- 难点1：
  - 如何定义足够稳健的 `高相关风险触发条件`，避免对低风险场景过度干预。
- 难点2：
  - 如何在改善 `ISI` 弱分量恢复的同时，不显著破坏 `PJ` 幅值保持度与整体估计一致性。
- 难点3：
  - 如何在 `正交化 / 条件化 / 相关性约束联合再估计` 几类局部路线之间选出最适合当前代码基础的实现方式。

## 与现有方法差异

- 与小论文已有方法差异：
  - 第一创新点重点解决 `活跃频率支持识别` 与 `多分量联合分解`；
  - 当前阶段3框架重点解决 `已识别支持集条件下` 的 `相关性诊断、局部解耦与弱分量稳定恢复`；
  - 两者关系是 `前端识别 + 后端增强`，而不是重复分解同一问题。
- 与常见整体重估式改进的定位差异：
  - 当前框架不打算重写整套分解器，而是保持前端主线稳定，仅对高风险相关子空间做条件触发的局部处理；
  - 这一差异是当前方法框架的定位口径，不构成已验证优劣结论。
