# 缺口分析

本文件基于当前已完成流程中的既有检索记录与正式文档整理，不新增外部检索结果。

## 1. 使用边界

- 本文件只沉淀当前可保留的研究缺口判断。
- 所有判断均以现有阶段1、阶段2检索记录和当前正式创新点口径为基础。
- 本文件不提前把第二创新点写成已经验证成立的结果。

## 2. 现有文献已经说明的成熟部分

由当前已整理文献可中立看出，以下部分已有较成熟研究基础：

1. 抖动术语、分类与测量对象
   - 以 `Balestrieri 2019` 为代表。
2. 经典抖动分解路线
   - 以 `Dou 2006` 为代表。
3. 高速链路中的确定性抖动分解基线
   - 以 `Duan & Chen 2018/2019` 为代表。
4. 示波器 / TIE 场景下的近年测量与分析问题
   - 以 `Chen 2023`、`Moussa 2024` 为代表。
5. 近年仍持续出现的新型抖动分量分析方法
   - 以 `Deng 2024`、`Wu 2026` 为代表。

这说明：第二创新点不能把“是否值得研究抖动分解”本身当作缺口，而应进一步下沉到更具体的未闭环问题。

## 3. 与当前第二创新点最直接相关的缺口判断

结合现有文献与当前已完成小论文暴露出的限制，可整理出以下更具体的缺口判断。

### 3.1 当前真正缺的不是“再找一种分解方法”，而是高相关子空间中的稳定恢复机制

- 已完成小论文已经较好覆盖：
  - `活跃频率支持识别`
  - `多分量联合分解`
- 当前仍未闭环的是：
  - 在 `低频 PJ`、`弱 ISI`、有限观测窗口共同作用下，`PJ` 子字典与 `ISI` 子字典的残余共线性会导致弱分量恢复不稳。

这是当前第二创新点正式主线成立的直接缺口来源。

### 3.2 近年文献能证明问题仍重要，但没有直接把当前问题彻底做透

- `Chen 2023`、`Moussa 2024` 说明示波器场景和 TIE 测量问题仍活跃；
- `Deng 2024`、`Wu 2026` 说明 `jitter analysis / component analysis` 近年仍有新方法；
- `Guo 2023` 与 `Peng 2025` 提供了与高相关估计、有限样本稳健性相关的方法线索。

但就当前已整理材料而言，还不能据此得出：

- “低频 `PJ-ISI` 共线性导致的弱分量恢复问题已经被直接解决”
- “某一类结构化解耦实现路线已经被当前领域公认最佳”

因此，现有文献更多证明“问题仍重要”“方法线索存在”，而不是替代你当前第二创新点本身。

### 3.3 当前缺口更接近“分解增强”，而不是完整建模体系

- 当前正式主线已经明确：第二创新点优先落在 `抖动分解增强` 侧。
- 现有建模相关补充文献主要来自候选比较和备选路线保留，尚不足以直接支撑把当前第二创新点改写成完整 `抖动建模` 方案。

所以当前可保留的中立判断是：

- `抖动建模` 仍是大论文整体主线中尚未充分展开的一部分；
- 但它目前不是当前第二创新点正式主选方案的直接核心缺口。

## 4. 当前文献梳理仍然存在的不足

这些不是“第二创新点研究缺口”，而是“当前文献整理自身还未补齐的缺口”。

1. 方法级文献缺口
   - 还没有围绕 `structured decoupling / coherent subspace / related dictionary` 做一轮更系统的方法级检索。
   - 因此，当前仍缺“哪种局部解耦路线更适合作为正式主线”的文献层支撑。

2. 实验设计文献缺口
   - 还没有围绕 `评价指标`、`实验变量覆盖`、`基线代表性` 做一轮专门检索。
   - 这会影响阶段4实验设计的文献完备性。

3. 建模主线文献缺口
   - 当前虽然已经保留若干 `PSIJ / surrogate modeling / polynomial chaos` 线索，但还没有单独展开“抖动建模”主线的近年文献。

## 5. 当前可保留的正式判断

1. 当前第二创新点最有根据的研究缺口，是：
   - `低频 PJ-ISI 共线性条件下的弱分量稳定恢复问题`
2. 这一缺口同时满足：
   - 来自已完成小论文暴露出的真实限制；
   - 与经典抖动分解主线连续；
   - 能被近年文献证明其问题背景在当前仍重要；
   - 适合继续沿仿真闭环推进。
3. 当前还不能写成正式结论的部分是：
   - 具体哪一种结构化解耦实现路线最优；
   - 哪组实验指标最能稳定刻画收益与副作用；
   - `抖动建模` 主线最终如何在大论文中展开。

## 6. 下一步建议

- 若继续推进文献工作，优先围绕阶段4需求补两类检索：
  - 实验变量、评价指标和基线代表性相关文献；
  - 结构化解耦 / 高相关子空间再估计相关方法文献。
- 当前 `01_文献梳理` 已经足以作为正式文稿中的第一版文献整理入口，但仍应视为可继续扩展版本。
