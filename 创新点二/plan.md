# 第二创新点 plan

## 使用目的

本文件用于统一管理第二创新点从构思到实验到写作的 7 个总阶段，只负责回答三件事：

1. 当前做到哪一步；
2. 每一步的正式产出放在哪里；
3. 模块目录与阶段推进之间是什么关系。

本文件不替代 `创新点构思过程\创新点遴选工作流\第二创新点遴选工作流规范.md`，也不替代各轮次工作流文档。

## 目录组织原则

- 总阶段统一由本文件管理，不再把阶段本身直接做成目录。
- `创新点二` 下按长期模块分目录：
  - `正式文档`：放后续会持续维护和引用的正式材料。
  - `创新点构思过程`：放第二创新点构思、筛选和遴选的过程材料。
  - `过程记录`：放文献检索记录、实验记录等过程日志。
  - `图表`、`仿真与代码`、`输出结果`：放后续实验与写作资产。
- `创新点构思过程\创新点遴选工作流\` 统一保存阶段1的规则文件与 skill 草稿。
- 未经你再次确认，不把第二创新点的具体方向写入本文件。

## 与现有工作流文件的关系

你当前想要的是“按第二创新点从构思到实验到写作的总阶段管理”，而工作区现有规范是“按创新点遴选工作流管理构思过程”。这两套阶段不是同一层级。

更准确的关系是：

- `阶段1：创新点方向确认` 是总阶段。
- `创新点构思过程\工作流轮次X\` 下的 `阶段一` 到 `阶段五`，都是 `阶段1：创新点方向确认` 的内部子阶段。
- `阶段2` 到 `阶段7` 是方向确认之后的后续研究与写作阶段，不应再映射到 `工作流轮次X` 的命名上。

| 总阶段 | 对应工作流材料 | 用法 |
| --- | --- | --- |
| 阶段1：创新点方向确认 | `创新点构思过程\工作流轮次X` 下的阶段一到阶段五 | 作为方向确认的分析与筛选过程留痕。 |
| 阶段2：研究目标定义 | 无直接对应 | 需要在方向确认后单独形成正式文档。 |
| 阶段3：方法框架设计 | 无直接对应 | 需要单独形成正式文档。 |
| 阶段4：实验设计 | 无直接对应 | 需要单独形成正式文档。 |
| 阶段5：实现与初步验证 | 无直接对应 | 需要单独形成正式文档。 |
| 阶段6：结果分析与创新点确认 | 无直接对应 | 需要单独形成正式文档。 |
| 阶段7：论文撰写 | 无直接对应 | 需要单独形成正式文档。 |
